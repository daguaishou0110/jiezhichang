# jiezhichang · 一区公开数据写法门户

静态站点：医学一区公开数据写法说明（客户认知页）。

## 本地预览

用浏览器打开 `index.html`，或：

```bash
npx serve .
```

## 页面

| 文件 | 说明 |
|------|------|
| index.html | 五种写法门户 |
| two-paths.html | 两种医学一区 |
| crc-microbiome.html | 结直肠菌群方案 |
| confidence.html | 底气页 |
| lists/ | 完整期刊列表 |

## Render

连接本仓库后选择 **Static Site**，Publish directory = `.`（仓库根目录）。
也可使用根目录 `render.yaml` Blueprint。

仓库：https://github.com/daguaishou0110/jiezhichang
